# VideoTime（视频时长统计）

> 自动扫描并统计文件夹中所有视频的时长，按目录汇总视频总时间，树形展示，一键复制/导出结果，可用于网课视频时长分析（欢迎帮我提意见）

VideoTime 无需逐个打开视频，扫描后即可在几秒内汇总出每个文件夹的视频总时长，并用清晰的树形列表呈现。

---

## 主要功能

- **自动统计视频时长**：选择一个或多个文件夹，即可统计其中（可选含所有子目录）视频的总时长与数量。
- **多文件夹统计**：支持多行输入，一次可同时统计多个文件夹（每行可输入 / 浏览 / 拖放，`+` 加行、`-` 删行），结果合并到同一棵树；自动检测重复或嵌套的路径。
- **多视频格式支持**：直接读取二进制时长头，支持 mp4 / mov / m4v / 3gp、mkv / webm、avi、wmv / asf，不解码视频，秒级完成统计。
- **树形展示结果**：按文件夹层级展示，每一项清楚标注 `文件夹名 / 总时长 / 视频数`，一眼看清各目录的占比。
- **累计汇总**：每个文件夹的时长 = 它直接包含的视频 + 所有子文件夹视频之和，方便看出哪类内容耗时最多。
- **结果筛选**：按名称、时长、视频数过滤结果树，命中的名称会高亮显示，枝干合计自动按过滤后的内容重算。
- **扫描进度条 + 取消**：扫描时窗口底部显示内嵌文字的进度条（收集阶段滑动动画、解析阶段显示百分比），随时可点 [取消] 中止；完成后短暂满格即自动消失。
- **导出报表**：右键一键导出 **CSV**（Excel/WPS 可直接打开）或 **HTML** 报表，含失败明细。
- **命令行模式**：`VideoTime.exe -d 文件夹 -r -o 报表.csv` 无界面批量统计，方便脚本调用。
- **缺失自动提醒**：遇到读不了的文件、进不去的目录或过深的目录，扫描结束后会弹窗汇总，并在 `log.txt` 里写明每个问题的路径和原因。
- **复制与分享**：支持复制选中行、复制当前可见的全部文本，也可一键保存为**高清**图片（PNG / BMP，3 倍像素渲染）用于发圈或写报告。
- **多种选目录方式**：支持直接输入路径、点选浏览、或直接把文件夹拖进窗口。
- **日志分级**：可在 [设置] 中调整日志输出范围（全部 / 仅警告及以上 / 仅错误 / 关闭），方便按需查看与定位问题。
- **记住你的选择**：上次选择的多个目录、选项与日志级别会自动保存，下次打开即可直接使用。

## 快速上手

1. **选择目录**：在「文件」标签页输入路径、点 [浏览] 选择，或直接拖一个文件夹到路径输入框上。想同时统计多个文件夹，就点右上角 `[+]` 加几行，每行填一个目录；`[-]` 删除某行。
2. **决定范围**：勾选"包含子文件夹"，可统计所选目录下的所有层级；不勾选则只统计该目录直属的视频。
3. **点击 [查询]**：窗口底部出现进度条（先收集目录、再显示百分比），扫完短暂显示 100% 后自动消失，结果树占满界面。
4. **（可选）筛选结果**：点顶部菜单「筛选」，按名称、时长、视频数过滤结果树；点 [清除] 可随时还原全部结果。
5. **（可选）设置日志级别**：点右上角 [设置]，选择日志输出范围（全部 / 仅警告及以上 / 仅错误 / 关闭）。
6. **（可选）命令行统计**：`VideoTime.exe -d 文件夹 [-r] [-o 报表.csv 或 .html]`，不指定 `-o` 时直接打印结果。

> 目录较大时，可随时点 [取消] 中止扫描；扫描结束顶部显示总时长结果。统计多个目录时，若存在重复或互相嵌套的路径，会弹出提示，确认后才会继续。

## 结果怎么看

每条结果显示为：

```
课程视频  234时56分34秒  [视频401]
  ├ 01 基础阶段  155时45分23秒  [视频221]
  └ 02 提高阶段   79时11分12秒  [视频177]
```

- **时长**：该文件夹含其所有子文件夹的**累计总时长**（仅累加成功解析的文件）。
- **[视频N]**：该文件夹（含子文件夹）内的视频数量，按视频扩展名统计，**含读取失败的文件**。总时长只累加成功解析的文件，失败文件的时长计为 0，具体失败原因见 `log.txt`。
- 列表默认展开前 2 层（包括根目录），更深的层级可点击 `+` / `-` 手动展开或收起。
- 统计多个文件夹时，若两个根目录同名，会以完整路径区分显示。

## 筛选结果

点顶部菜单「筛选」进入筛选面板，填写条件后按 `Enter` 或点 [过滤] 立即生效：

- **名称**：文件夹名包含的关键字（不区分大小写）。
- **时长（小时）**：最小 / 最大累计时长区间。
- **数量**：最小 / 最大视频数区间。

时长和数量条件只对**最底层的文件夹**生效；应用后只保留符合条件的分支，枝干会自动按过滤后的内容重新合计，顶部显示 `过滤合计`。命中的名称会**高亮显示**。点 [清除] 即还原全部节点与原始展开状态。

## 复制与导出

- **复制选中项**：选中某一行后按 `Ctrl+C`，或右键 → 复制，即可复制该节点。
- **复制总时间栏文字**：顶部显示总时间的那一行，可以鼠标直接拖选局部，按 `Ctrl+C` 或右键 → 复制整段。
- **复制当前显示的全部文本**：右键 → 复制当前可见文本，可把可见结果一次性复制出来。
- **保存为图片**：右键 → 保存当前文本为图片，可保存为 PNG 或 BMP；图片为**高清渲染**（3 倍像素 / 288dpi），适合分享。结果行数特别多时自动截断为前 30000 行，并附一行提示改用「复制当前界面文本」。
- **导出报表**：右键 → 导出报表…，可保存为 **CSV**（Excel 打开）或 **HTML**（浏览器打开），内含失败明细。命令行下用 `-o 文件.csv|.html` 也可生成。

## 你可能会看到的提示

软件会在三处告诉你扫描情况：**顶部时间栏**（总时间）、**弹窗**（需要你确认的重要提示）、**日志文件 `log.txt`**（所有明细）。

| 遇到的情况 | 顶部时间栏 | 弹窗 | 日志 |
|---|---|---|---|
| 扫描正常完成 | 显示总时间 | 不弹 | 记一条信息 |
| 有文件/目录出问题 | 仍只显示总时间 | 弹出警告，汇总问题数量 | 记录每个出问题的文件/目录及原因 |
| 文件夹路径输错 | 提示"路径无效" | 不弹（单路径时） | 记一条警告 |
| 多个路径中部分无效 | 询问是否忽略后继续 | 弹出警告列出无效路径 | 记一条警告 |
| 多个路径有重复或嵌套 | 询问是否允许重复计时 | 弹出提示列出重叠项 | — |
| 扫描中途点 [取消] | 提示"扫描已取消。" | 不弹 | 记一条信息 |
| 程序内部出错 | — | 弹出错误 | 记一条错误 |
| 复制/保存出问题 | — | 视情况弹出 | 记一条警告或错误 |

> **日志文件 `log.txt`**：和程序放在同一文件夹，自动记录。每行带时间、等级（信息/警告/错误）和内容。看到警告弹窗时，想查"具体是哪个文件出了问题、为什么"，打开 `log.txt` 就能找到。

## 常见问题 (FAQ)

**点 [查询] 没有反应？**
请确认输入的是正确存在的文件夹路径；若开启了"包含子文件夹"，也请确认目标文件夹内确含视频。

**统计的时长和单个视频对不上？**
多数文件夹显示的是**累计时长**（含子文件夹），并非单文件时长。

**为什么有些视频提示读取失败？**
个别文件格式特殊（缺少标准视频信息头）或文件损坏时无法读取，这类文件不会被计入总时长。扫描结束时软件会弹出警告窗告诉你一共有几个文件没读到，并且每个文件的路径和原因都会写进 `log.txt`，方便你定位。

**能导出到 Excel / PDF 吗？**
可以导出 **CSV**（用 Excel/WPS 打开）或 **HTML**（浏览器查看）报表：界面右键 → 导出报表…，或命令行 `-o`。此外还支持复制为文本、保存为 PNG/BMP 图片；暂不支持直接导出 PDF。

**能一次统计多个文件夹吗？**
可以。在「文件」标签页点 `[+]` 添加多行，每行填一个文件夹，一次查询会并行统计并合并结果。多个目录重叠（重复或嵌套）时会提示确认，避免误算重复时长。

**过滤结果后还能恢复吗？**
可以。在「筛选」标签页点 [清除]，即可还原过滤前的全部节点、文字与展开状态。

## 命令行用法

```
VideoTime.exe -d <文件夹> [-r] [-o <输出文件>] [-h]
```

- `-d / --folder`：要统计的文件夹（必填）。
- `-r / --recursive`：递归统计子文件夹。
- `-o / --out`：输出报表（`.csv` / `.html`，默认 CSV）；省略则控制台打印结果树。
- `-h / --help`：显示帮助。

> 不带参数启动即打开图形界面。命令行成功退出码为 0，目录不存在或参数错误为 1。
